# RPHC Smart Management System

ระบบบริหารจัดการภายในโรงพยาบาลส่งเสริมสุขภาพตำบล — เวอร์ชันใช้งานจริง (ฐานข้อมูลจริง + ระบบล็อกอิน)

สร้างด้วย **Next.js 16 + PostgreSQL** พร้อม deploy บน Vercel

---

## ⚡ ติดตั้งใช้งานใน 4 ขั้นตอน

### ขั้นที่ 1 — สร้างฐานข้อมูล PostgreSQL (ฟรี)

แนะนำ **Neon** เพราะมีแพ็กเกจฟรีและตั้งค่าง่ายที่สุด

1. เข้า https://neon.com แล้วสมัครสมาชิก (ล็อกอินด้วย GitHub ได้เลย)
2. กด **Create project** ตั้งชื่อโปรเจกต์ เช่น `rphc`
3. เลือก Region ที่ใกล้ที่สุด (แนะนำ **Singapore** สำหรับประเทศไทย)
4. เมื่อสร้างเสร็จ จะมีช่อง **Connection string** ให้คัดลอก
   หน้าตาประมาณนี้ → `postgresql://user:password@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
5. **คัดลอกเก็บไว้** จะใช้ในขั้นที่ 3

> ทางเลือกอื่นที่ใช้ได้เหมือนกัน: Supabase, Vercel Postgres, หรือ PostgreSQL ที่ติดตั้งบนเซิร์ฟเวอร์ของหน่วยงานเอง

### ขั้นที่ 2 — สร้างรหัสลับสำหรับระบบล็อกอิน

ระบบต้องใช้ข้อความสุ่มยาว ๆ เพื่อเข้ารหัสการล็อกอิน สร้างได้จาก:

- เว็บ https://generate-secret.vercel.app/32 (กดแล้วคัดลอกได้เลย)
- หรือใน PowerShell: `[Convert]::ToBase64String((1..32|%{Get-Random -Max 256}))`

**เก็บข้อความที่ได้ไว้** จะใช้ในขั้นถัดไป

### ขั้นที่ 3 — Deploy ขึ้น Vercel

1. push โค้ดนี้ขึ้น GitHub (ดูหัวข้อ "การใช้ git" ด้านล่าง)
2. เข้า https://vercel.com/new → Import repo
3. **ก่อนกด Deploy** ให้เปิดหัวข้อ **Environment Variables** แล้วใส่ 2 ค่านี้:

   | Name | Value |
   |------|-------|
   | `DATABASE_URL` | connection string จากขั้นที่ 1 |
   | `AUTH_SECRET` | ข้อความสุ่มจากขั้นที่ 2 |

4. กด **Deploy** รอประมาณ 1-2 นาที

### ขั้นที่ 4 — ติดตั้งระบบครั้งแรก

1. เปิด URL ที่ Vercel ให้มา แล้วต่อท้ายด้วย `/setup`
   เช่น `https://your-app.vercel.app/setup`
2. กรอกชื่อ-สกุล ชื่อผู้ใช้ และรหัสผ่านของ **ผู้ดูแลระบบคนแรก**
3. ติ๊ก "ใส่ข้อมูลตัวอย่างให้ด้วย" ถ้าต้องการทดลองใช้ก่อน
   (ถ้าจะใช้งานจริงให้เอาเครื่องหมายออก)
4. กดปุ่มติดตั้ง — ระบบจะสร้างตารางฐานข้อมูลทั้งหมด (47 ตาราง) ให้อัตโนมัติ

เสร็จแล้วเข้าใช้งานได้ทันที

> **หน้า `/setup` จะใช้ได้ครั้งเดียว** หลังมีบัญชีผู้ดูแลระบบแล้วจะถูกปิดอัตโนมัติ
> การเพิ่มผู้ใช้คนอื่นทำได้ที่เมนู **ตั้งค่าระบบ → บัญชีผู้ใช้งาน**

## ✅ สิ่งที่ทำเสร็จแล้ว

### ระบบพื้นฐาน
- ระบบล็อกอินจริง (รหัสผ่านเข้ารหัสด้วย bcrypt, session แบบ JWT ใน httpOnly cookie)
- สิทธิ์ผู้ใช้งาน **8 บทบาท** บังคับใช้ที่ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนเมนู
- **Audit Log** บันทึกทุกการเพิ่ม แก้ไข ลบ เข้า-ออกระบบ
- **ประวัติการแก้ไข** เก็บค่าเดิม→ค่าใหม่รายฟิลด์
- บันทึกผู้บันทึกข้อมูลและวันที่บันทึกทุกรายการ
- หน้าติดตั้งระบบครั้งแรก สร้างตารางอัตโนมัติ
- ตั้งค่าข้อมูลหน่วยงานสำหรับใช้เป็นหัวเอกสารที่พิมพ์ออก

### ทะเบียนหลักครบ 10 ระบบงาน
บุคลากร · คลังยา · คลังวัคซีน · ยานพาหนะ · ครุภัณฑ์/พัสดุ · ระบาดวิทยา ·
แผนยุทธศาสตร์ · มาตรฐาน PCU · อนามัยโรงเรียน · อสม./ประชุม

ทุกระบบมี: เพิ่ม/แก้ไข/ลบ · ค้นหา · แบ่งหน้า · Export CSV (เปิดใน Excel ได้) · พิมพ์

### ระบบการลา — ตามระเบียบสำนักนายกรัฐมนตรีฯ พ.ศ. 2555
- ครบ **11 ประเภทการลา** พร้อมสิทธิ์วันลาตามระเบียบ
- คำนวณวันลาเฉพาะ**วันทำการ** (ตัดเสาร์-อาทิตย์และวันหยุดราชการ)
- ตรวจสิทธิ์คงเหลืออัตโนมัติ กันไม่ให้ลาเกินสิทธิ์
- เตือนตามระเบียบ เช่น ลาป่วย ≥ 30 วันต้องแนบใบรับรองแพทย์, ลาอุปสมบทต้องยื่นล่วงหน้า 60 วัน
- สายอนุมัติ (รออนุมัติ → อนุมัติ/ไม่อนุมัติ) เฉพาะผู้มีอำนาจ
- **พิมพ์ใบลาตามแบบราชการ** พร้อมตารางสถิติการลาและช่องลงนาม
- เลขที่ใบลาอัตโนมัติตามปีงบประมาณ (เช่น ล.0001/2569)

### คลังยา/วัคซีน — ระบบเคลื่อนไหวสต๊อกจริง
- **Stock Card** ทะเบียนรับ-จ่ายรายรายการ พร้อมยอดคงเหลือต่อเนื่อง
- **FEFO** ตัดจ่ายล็อตที่หมดอายุก่อนอัตโนมัติ (ตัดข้ามหลายล็อตได้)
- กันการจ่ายเกินยอดคงเหลือ
- **ทะเบียนรับ-จ่าย (รบ.301)** รายเดือน พร้อมยอดยกมา-รับ-จ่าย-คงเหลือ และช่องลงนาม
- แจ้งเตือนยา/วัคซีนหมดอายุ ใกล้หมดอายุ 90 วัน และต่ำกว่าจุดสั่งซื้อ
- แยกคลังใน/คลังนอก และล็อต/วันหมดอายุรายล็อต

### มาตรฐาน PCU
- ใส่เกณฑ์**คู่มือคุณภาพมาตรฐานบริการสุขภาพปฐมภูมิ พ.ศ. 2566** ไว้ให้แล้ว
- 8 หมวด 59 ข้อ รวม **253 คะแนน** พร้อมเกณฑ์ผ่านรายหมวด (หมวด 1-4 ต้องผ่านทุกข้อ, หมวด 5-8 ผ่านที่ 80%)

### Dashboard และรายงาน
- การ์ดสรุป: ยาใกล้หมดอายุ · วัคซีนใกล้หมดอายุ · ใบเบิก/ใบลารออนุมัติ · เจ้าหน้าที่ลาวันนี้
- กราฟผู้รับบริการรายเดือน และสัดส่วนประเภทบริการ
- งานค้างที่ต้องติดตาม (คำนวณจากข้อมูลจริง)
- ข่าวประชาสัมพันธ์
- **สร้างร่างรายงานราชการ 4 แบบ** จากข้อมูลจริง: รายงานประจำเดือน · SAR · รายงานผลโครงการ · รายงานประชุม อสม.
  ดาวน์โหลดเป็น Word (.doc) หรือข้อความได้

## 🔐 ความปลอดภัยและ PDPA

- รหัสผ่านเก็บเป็น hash (bcrypt) ไม่เก็บรหัสจริง
- ตรวจสิทธิ์ทุก API ที่ฝั่งเซิร์ฟเวอร์ — ต่อให้แก้หน้าเว็บก็เข้าไม่ได้
- ป้องกัน SQL injection ด้วย parameterized query และ whitelist ชื่อคอลัมน์
- Audit Log ตรวจสอบย้อนหลังได้ว่าใครทำอะไรเมื่อไหร่

**สิ่งที่ต้องทำเพิ่มก่อนเก็บข้อมูลผู้ป่วยจริง:** จัดทำบันทึกรายการประมวลผลข้อมูล (RoPA),
แบบขอความยินยอม, นโยบายการเก็บ/ทำลายข้อมูล, ตั้งค่า backup อัตโนมัติของฐานข้อมูล
และเปิด Vercel Authentication หากไม่ต้องการให้บุคคลภายนอกเข้าถึง URL

## 🗂️ โครงสร้างโค้ด

```
app/
├── (app)/            หน้าที่ต้องล็อกอินก่อน (มี sidebar)
│   ├── dashboard/    หน้าแรก
│   ├── m/[module]/   หน้าทะเบียนของแต่ละระบบงาน
│   ├── reports/      สร้างรายงาน
│   ├── audit/        Audit Log
│   └── settings/     ตั้งค่าระบบ + จัดการผู้ใช้
├── api/              API ทั้งหมด (ตรวจสิทธิ์ทุกเส้น)
├── print/            เอกสารสำหรับพิมพ์ (ใบลา ฯลฯ)
├── login/  setup/    หน้าเข้าสู่ระบบ และติดตั้งครั้งแรก
components/           ส่วนประกอบหน้าจอที่ใช้ร่วมกัน
lib/
├── schema.ts         สคีมาฐานข้อมูลทั้งหมด (47 ตาราง)
├── modules.ts        นิยาม 10 ระบบงาน + ฟิลด์ + เมนูย่อย
├── permissions.ts    สิทธิ์ 8 บทบาท
├── leave-types.ts    11 ประเภทการลาตามระเบียบ 2555
├── stock.ts          ระบบเคลื่อนไหวสต๊อก + FEFO
└── seed.ts           ข้อมูลตั้งต้น (เกณฑ์ PCU) + ข้อมูลตัวอย่าง
```

**อยากเพิ่มฟิลด์ในทะเบียนไหน** แก้ที่ `lib/modules.ts` แล้วเพิ่มคอลัมน์ใน `lib/schema.ts`
หน้าตาราง ฟอร์ม ค้นหา และ Export จะปรับตามให้อัตโนมัติ
